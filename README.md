# Log Parser (name TBD)

> [!CAUTION]
> This project is still in development.

Written in Java, an implementation of a TUI for parsing streamed or log files. Inspiration from [here](https://learncodethehardway.com/blog/32-very-deep-not-boring-beginner-projects/).

## Features

- Parsing of log files
- Streaming of log data
- Real-time parsing and display via terminal interface

Uses Java IO libraries BufferedReader and FileReader/StreamReader for reading and parsing log files. The TUI interface is frameworked with [Lanterna]()
